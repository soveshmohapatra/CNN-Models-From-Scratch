What does a neural network "see" when it looks at an image?

I trained a CNN from scratch on MNIST and extracted the learned filters. The results are beautiful:

🔹 First layer filters: Edge detectors (vertical, horizontal, diagonal)
🔹 Feature maps: Sparse activations showing where specific patterns appear
🔹 Hierarchical learning: Simple features → complex combinations

The network independently discovered the same features found in mammalian visual cortex—oriented edge detectors in early layers.

This is the power of deep learning: not hand-crafted features, but learned representations optimized for the task.

Full training logs, visualizations, and code in the repo.
